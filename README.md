## RoboCode Royal Install
### Java
Install java jdk (v11 or greater) (https://www.oracle.com/java/technologies/downloads/#jdk27-windows)
### RoboCode
From GitHub releases (https://github.com/robocode-dev/tank-royale/releases)
1) download gui jar (https://github.com/robocode-dev/tank-royale/releases/download/v1.4.0/robocode-tankroyale-gui-1.4.0.jar)
2) download server jar (https://github.com/robocode-dev/tank-royale/releases/download/v1.4.0/robocode-tankroyale-server-1.4.0.jar)
2) install python version (in venv) `python -m pip install robocode-tank-royale==1.4.0`
### Robo Tanks
